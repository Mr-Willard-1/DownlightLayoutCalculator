# Downlight Layout Calculator

Native Android Studio application for professional downlight layout planning.

Current release: **v1.9 – Live Kitchen Preview**

Features include millimetre-based layout planning, multiple grid presets, custom layouts, L/T-shaped rooms, drag-adjusted downlights, joist/exclusion zones with repeating centres, cut-out clearance, kitchen cupboard/worktop shadow-reduction planning, bathroom/wetroom regulation-aware placement, saved projects, dimensioned PDF design plans, and pre-export plan preview.

The Kitchen cupboard/worktop editor includes a live room preview so the selected wall, cupboard/worktop run and task-light line can be verified before adding the run.

## Android Studio

Open the repository root in Android Studio, allow Gradle to sync, then run the `app` configuration on an emulator or Android device.

Minimum Android version: Android 8.0 (API 26).
